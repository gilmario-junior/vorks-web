# VORKS WEB

Frontend oficial do sistema VORKS.

## Tecnologias

- Next.js
- TypeScript
- TailwindCSS
- shadcn/ui

## Objetivo

Sistema SaaS para organização operacional e pedidos via WhatsApp.

## Ambiente

### Instalação

```bash
npm install
```

### Executar projeto

```bash
npm run dev
```

## Estrutura

```txt
src/
```
